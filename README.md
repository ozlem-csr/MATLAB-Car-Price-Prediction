# MATLAB Car Price Prediction

A machine learning-based car price prediction and classification system developed using MATLAB.

## Project Overview

This project analyzes vehicle data to predict car prices, classify vehicles into different price segments, and group similar vehicles using machine learning algorithms.

## Features
- Car price prediction using Linear Regression.
- Vehicle classification using Decision Tree, KNN and SVM.
- Vehicle clustering using Gaussian Mixture Model (GMM).
- Data preprocessing and normalization.
- Model evaluation and performance comparison.
- Data visualization with MATLAB plots.

## Machine Learning Algorithms
- Linear Regression
- Decision Tree
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Gaussian Mixture Model (GMM)

## Dataset

The project uses a dataset containing 100 vehicle records with features such as:
- Model year
- Mileage
- Fuel type
- Transmission type
- Vehicle condition
- Price

## Model Evaluation

- 80% training and 20% testing split.
- MAE, MSE and RMSE for price prediction.
- Confusion matrix and accuracy for classification.
- Visual comparison of model results.

## Technologies
- MATLAB
- Machine Learning
- Data Analysis
- CSV

## Project Structure
- `main.m` – Main MATLAB source code.
- `Galeri_Verileri.csv` – Vehicle dataset.
- `RAPOR.pdf` – Project report and result visualizations.
